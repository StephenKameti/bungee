# User journeys

Every tool follows the same five steps so the product feels like one studio: Brief, Read back, Explore, Refine, Deliver.

| Step | What the user does | What the product does | Moment of delight |
|---|---|---|---|
| Brief | Pastes, uploads or speaks the brief, picks a brand kit and tools | Extracts text from any format, shows what is still missing | A chat screenshot becomes a clean brief |
| Read back | Checks the spine, edits, answers at most one question | Fills the spine, tags assumptions, shows the plan and timing | "It understood the brief better than the brief" |
| Explore | Scans options, shortlists, compares | Streams a spread of options with visible progress | Six to eight genuinely different ideas |
| Refine | Directs with chips or a sentence, generates previews | Rebuilds ideas, not just words; keeps versions | "Make it simpler" actually simplifies |
| Deliver | Exports or shares | Route book, PDF, slides, spreadsheet, calendar file | A client ready file in one click |

## The hero journey: one brief, five tools
1. A strategist uploads a brief and runs Campaign Strategy. Chooses an insight and a territory.
2. The chosen platform flows into Key Visual. The creative director shortlists three routes.
3. The winning route flows into Retail Theatre and Content Calendar, carrying copy and look.
4. The strategy deck outline flows into Deck Designer with the route imagery.
5. Everything lives in one project, exported as a single share link for the client.

## Product description

### Your deck looks like a template.

Make it look studio made. Copy, type and all.

**What you get**

* Image prompts that generate fully designed slides, your copy rendered inside
* Three named design languages invented for your brand and its market
* Type locked on every slide, so the deck reads as one piece
* Your comments actioned before design starts
* Works from a deck file, a PDF or a slide list

**Who it is for**

* Strategists and account leads with a big presentation coming
* Founders pitching investors
* Designers who want a strong first pass in minutes, not days

**Install in three steps**

Unzip your download first. Inside you will find the skill zip, a guide and your licence.

1. In Claude, open **Settings**, then **Capabilities**. Turn on **code execution and file creation**. Newer layouts call it **Create and edit files**.
2. Go to **Customize**, then **Skills**. Tap **+**, choose **Create skill**, then **Upload a skill**, and pick the skill zip.
3. Switch it on. Start a new chat and ask.

Works on any Claude plan, Free included, with code execution and file creation switched on.

## FAQ

**Does it work with my existing deck?**
Yes. Attach the deck or a PDF of it. It reads every slide and keeps your words.

**Do I need a paid Claude plan?**
No. Any plan works, Free included. Just switch on code execution and file creation in Settings first.

**Will every slide feel like the same deck?**
Yes. The design language and the type are locked before the first slide, then held across all of them.

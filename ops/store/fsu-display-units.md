## FAQ

**Why are the panels blank?**
On purpose. Image models mangle small type. You add the copy in post, so feedback means a quick text change, not a new render.

**Do I need a paid Claude plan?**
No. Any plan works, Free included. Just switch on code execution and file creation in Settings first.

**My current prompts look too plain. Can it fix them?**
Yes. Paste them in and say "too plain". It rebuilds each unit around one strong theatrical idea.

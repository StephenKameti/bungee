# Bungee brand kit

Everything in one folder: logos, colours, type.

## Logos

| File | Use |
| --- | --- |
| `../bungee-logo-trim.png` | Primary. Slate letters, lime tick. Light grounds only |
| `../bungee-logo-transparent.png` | Primary with clear space, for compositing |
| `../bungee-logo-reversed-trim.png` | Reversed. White letters, lime tick. Dark grounds. Waiting for Stephen's approval |
| `../bungee-logo-reversed.png` | Reversed with clear space |
| `../tick.png` | The lime tick on its own |
| `favicon.png` | App icon: the tick on a slate tile |

Never recolour, stretch or redraw the logo.

## Colour

| Token | Hex | Use |
| --- | --- | --- |
| Slate | #3F414B | Logo ink, headlines, dark grounds |
| Lime | #BEFD50 | The tick, the cord, highlights. Never text on a light ground |
| Paper | #F6F6F2 | Default canvas |
| Hairline | #DCDDD6 | Rules and card borders |
| Muted | #6C6E77 | Secondary labels on paper (the films use #7E8089; the web uses this darker tone to pass contrast) |
| White | #FFFFFF | Cards on paper, text on slate |

## Type

* Display: Instrument Serif, regular and italic.
* Interface and body: Hanken Grotesk 400, 500 and 600. Never all caps.
* Prompts and code: JetBrains Mono.

Web font files and their SIL Open Font Licences are in `fonts/`.

## Signature device

The cord: a lime line drops from the top edge, overshoots and recoils once. It is the only place a bounce is allowed.
